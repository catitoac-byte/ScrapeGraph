01 · Laboratório aberto

Onze ferramentas abertas para levar à sala. Cada uma cabe numa demo de dez minutos.

Varremos o Hugging Face e o GitHub atrás de dados, bibliotecas, benchmarks e notebooks sobre dados e personas sintéticas. Saíram 69 itens. Estas onze são as que funcionam ao vivo numa aula, cada uma ilustrando uma estação do método, mais uma reserva para quem usa R.

Fonte: open_source_material.json, varredura de 17 out 2026 pelas APIs públicas do Hugging Face e do GitHub. Estrelas, downloads e licenças como a API mostrou nesse dia. Imagens: capturas das páginas públicas de cada projeto, no mesmo dia.
